# media / finals

Finished, exported media ready for use, delivery, or showcase.

## What belongs here

- Final exports (JPG, PNG, MP4, MOV, PDF)
- Delivery-ready, flattened, web- or print-sized files

## What does not belong here

- Raw camera files and unedited source (use `media/raw/` if approved)
- Project and edit working files (use `projects/`)

## Safety notes

- No secrets, API keys, or credentials.
- No private client data unless explicitly approved and released.
- Large approved media must use Git LFS (see `.gitattributes`).
