# media / raw

Source and raw media. Use with caution.

## What belongs here

- Raw camera files (CR2, CR3, NEF, ARW, DNG) and source footage (MOV, MXF)
- ONLY when their inclusion in this repository is intentionally approved

## What does not belong here

- Anything not approved for upload. Raw media is large and often better kept
  on external drives or dedicated storage, not in git.
- Finished exports (use `media/finals/`)

## Safety notes

- No secrets, API keys, or credentials.
- No private client data unless explicitly approved and released.
- Do NOT upload raw media by default. Confirm approval first.
- All approved large media must use Git LFS (see `.gitattributes`). Raw
  libraries can quickly exceed GitHub LFS storage and bandwidth limits.
