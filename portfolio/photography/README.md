# portfolio / photography

Finished photography selected for the portfolio.

## What belongs here

- Retouched, final, export-ready images (JPG, web-sized or print-sized)
- Best selects only, organized by shoot or theme if helpful

## What does not belong here

- Raw camera files (CR2, CR3, NEF, ARW, DNG) unless intentionally approved
- Unedited dumps or full take folders
- Client-private images not cleared for portfolio use

## Safety notes

- No secrets, API keys, or credentials.
- No private client data. Confirm model or client release before publishing.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
