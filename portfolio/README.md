# portfolio

Curated, finished work selected to showcase Sal's capabilities.

## What belongs here

- Polished, presentation-ready pieces only
- Organized into `photography/`, `videography/`, and `design/`
- Final exports suitable for sharing publicly

## What does not belong here

- Work-in-progress or unedited files
- Client-private deliverables (use `projects/`)
- Raw camera files or large source footage

## Safety notes

- No secrets, API keys, or credentials.
- No private client data. Only include work cleared for portfolio use.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
