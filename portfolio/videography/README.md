# portfolio / videography

Finished video work selected for the portfolio.

## What belongs here

- Final edited videos and exports (MP4, MOV)
- Showreels, highlight cuts, and finished deliverables cleared for showcase

## What does not belong here

- Raw source footage (MOV, MP4, MXF) unless intentionally approved
- Project/edit files and caches (keep working files in `projects/`)
- Client-private footage not cleared for portfolio use

## Safety notes

- No secrets, API keys, or credentials.
- No private client data. Confirm release before publishing.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`). Watch GitHub LFS storage limits with video.
