# portfolio / design

Finished graphic and visual design work for the portfolio.

## What belongs here

- Final design pieces and exports (PNG, PDF, JPG)
- Graphics, layouts, and visual work cleared for showcase

## What does not belong here

- Working source files mid-project (keep those in `projects/`)
- Client-private designs not cleared for portfolio use
- Large unflattened working files unless intentionally approved

## Safety notes

- No secrets, API keys, or credentials.
- No private client data.
- No raw or heavy source media unless intentionally approved. Large approved
  files (PSD, AI, INDD) must use Git LFS (see `.gitattributes`).
