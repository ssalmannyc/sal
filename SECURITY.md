# Security Policy

This is a proprietary personal portfolio and Sal Media repository. Protecting
the confidentiality, integrity, and ownership of its materials is a priority.

## Reporting a concern

Report the following privately to Sal at **sal@salman.nyc**:

- Security issues or vulnerabilities
- Exposed secrets (API keys, passwords, tokens, credentials, private keys)
- Accidental public exposure of private data
- Access concerns or suspected unauthorized access
- Copyright concerns
- Misuse of private media

Please include enough detail to understand and reproduce the concern, and
allow a reasonable amount of time for it to be reviewed and addressed before
taking any further action.

## What not to do

- **Do not open public GitHub issues** for sensitive security matters. Use
  the private email above instead.
- **Do not publicly disclose** any vulnerability, secret, or exposure.
- **Do not test** any systems, accounts, or infrastructure without prior
  written permission from Sal.
- **Do not access, copy, download, alter, or distribute** private materials
  in this repository or any related Sal Media systems.

## Authorization

Any testing, review, or handling of materials must be authorized in writing
by Sal in advance. Unauthorized activity is not permitted and may be
unlawful.
