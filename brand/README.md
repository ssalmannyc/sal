# brand

Brand identity assets for Sal and Sal Media.

## What belongs here

- Master brand assets and brand kits
- Anything shared across `logos/` and `guidelines/`
- Approved, finalized brand files

## What does not belong here

- Client project work (use `projects/`)
- Portfolio showcase pieces (use `portfolio/`)
- Scratch, drafts, or experiments

## Safety notes

- No secrets, API keys, or credentials.
- No private client data.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
