# brand / logos

Logo files for Sal and Sal Media.

## What belongs here

- Primary, secondary, and icon logo variations
- Light and dark versions
- Vector source (AI, SVG) and exported formats (PNG)
- Clear-space and favicon assets

## What does not belong here

- Full brand guidelines (use `brand/guidelines/`)
- Non-logo graphics or photography
- Client logos unless approved and properly licensed

## Safety notes

- No secrets, API keys, or credentials.
- No private client data.
- Third-party or client logos only when properly licensed or approved.
- Large approved source files must use Git LFS (see `.gitattributes`).
