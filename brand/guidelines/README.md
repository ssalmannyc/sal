# brand / guidelines

Brand standards and usage rules.

## What belongs here

- Brand guideline documents
- Color palettes, typography, and spacing rules
- Logo usage do's and don'ts
- Voice, tone, and style references

## What does not belong here

- The logo files themselves (use `brand/logos/`)
- Client project deliverables (use `projects/`)

## Safety notes

- No secrets, API keys, or credentials.
- No private client data.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
