# docs

Documentation for the repository and its workflows.

## What belongs here

- How-to notes, process docs, and workflow guides
- Reference material and internal documentation
- Index or overview docs for the repository

## What does not belong here

- Media assets (use `media/`, `portfolio/`, or `brand/`)
- Secrets or credential lists of any kind

## Safety notes

- No secrets, API keys, passwords, or credentials, even as examples. Use
  placeholders like `YOUR_API_KEY` if needed.
- No private client data.
- No raw media unless intentionally approved.
