# presentations

Decks and presentation material for partners, clients, and leadership.

## What belongs here

- Presentation files (PDF, PPTX, Keynote exports)
- Supporting visuals and slide assets
- Executive and client-facing decks

## What does not belong here

- Raw source media (keep in `media/` or `projects/`)
- Confidential financials or contracts unless explicitly approved

## Safety notes

- No secrets, API keys, or credentials.
- No private client data unless explicitly approved for this repository.
- Remove sensitive figures before committing a deck meant for a public repo.
- Large approved files must use Git LFS (see `.gitattributes`).
