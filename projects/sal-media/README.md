# projects / sal-media

Sal Media business and operations project work.

## What belongs here

- Sal Media specific working files and deliverables
- Operational documents, plans, and assets for the business
- In-progress materials tied to Sal Media

## What does not belong here

- Curated showcase pieces (use `portfolio/`)
- General brand assets shared across everything (use `brand/`)

## Safety notes

- No secrets, API keys, or credentials.
- No private client data, contracts, or financial records unless explicitly
  approved for this repository.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
