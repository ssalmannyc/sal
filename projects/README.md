# projects

Active and archived project work, organized one folder per project.

## What belongs here

- A subfolder per project (for example `sal-media/`)
- Working files, deliverables, and project notes
- In-progress work that is not yet portfolio-ready

## What does not belong here

- Curated showcase pieces (use `portfolio/`)
- Shared brand assets (use `brand/`)

## Safety notes

- No secrets, API keys, or credentials. Use environment variables outside the
  repo for anything sensitive.
- No private client data unless explicitly approved for this repository.
- No raw media unless intentionally approved. Large approved media must use
  Git LFS (see `.gitattributes`).
